# 📌 Listas y Tuplas en C#

Este proyecto contiene una serie de ejercicios desarrollados en **C#**, enfocados en el uso de **listas**, **tuplas** y estructuras básicas de programación. Todos los ejercicios se ejecutan desde un único archivo principal (`Program.cs`) mediante un menú interactivo en la consola.

---

## 📂 Estructura del proyecto

El proyecto está organizado de la siguiente manera:

- Program.cs :** Donde se Ejecutan los 5 ejercicios(Consola). 
- **Ejercicio 1:** Almacenamiento y visualización de asignaturas usando listas.
- **Ejercicio 4:** Ingreso y ordenamiento de números ganadores de la lotería usando listas.
- **Ejercicio 5:** Uso de tuplas para mostrar los números del 1 al 10 en orden inverso.
- **Ejercicio 8:** Verificación de palabras palíndromas utilizando tuplas.
- **Ejercicio 9:** Conteo de vocales en una palabra usando listas y diccionarios.


Cada archivo de ejercicio contiene la lógica correspondiente, la cual es llamada desde el método principal.
